## Export Market Intelligence 技能简介

**一句话定位**：面向中国 B2B 外贸工厂/出海企业的**全球市场深度调研与出海决策工具**，帮你判断"这个产品该不该做、往哪个国家卖、怎么打进去"。

---

### 它解决的核心问题

| 痛点 | 这个技能怎么解决 |
|---|---|
| **产品到底能不能出口？** | 拆解产品技术属性 → 查 HS 编码、退税率、监管条件，明确合规底线 |
| **全球市场有多大？** | 用 TAM/SAM/SOM 三层模型推演市场规模，标注数据来源和置信度 |
| **中国出口盘子怎么样？** | 拉全国出口额、产业带分布、前 10 大出口流向国 |
| **该往哪个国家卖？** | 把目标国分成四梯队（基石主力/高价值/高增长/利基），输出五维加权评分（满分 100），直接给出"优先突围 / 战略观察 / 暂缓进入"三色结论 |
| **竞争对手是谁、价格多少？** | 从外资巨头→国内上市公司→产业带白牌三层穿透，并给出 EXW→FOB→CIF→零售价的完整价格锚点 |
| **怎么找客户？** | 梳理阿里国际站/Google SEO/LinkedIn/行业展会等全渠道获客图谱 |
| **准入门槛高不高？** | 核查 CE/FDA/UL 等强制认证、301 关税、反倾销税、RCEP 优惠等贸易壁垒 |

### 交付物

最终产出一份 **Word (.docx) 格式的结构化报告**，内嵌对比表格，且所有关键数据都标注了置信度（🟢已查证 / 🟡估算 / 🔴推断），**严禁编造假数据**。

---

**适用场景**：你是工厂老板或外贸业务员，手里有个化工品（比如你常做的 SDIC/TCCA）或工业耗材，想搞清楚全球市场值不值得做、先打哪个国家、怎么定价合规——直接丢产品名给它就行。
